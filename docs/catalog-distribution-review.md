## Actual contents

`src/catalog/packaged.ts` imports `local-catalog/catalog.json`; Vite embeds it in the main JavaScript bundle. The raw stripped snapshot is public-repository material, not a separate Pages download. The full original upstream JSON is absent from this repository and its reachable history. `extract-archive.mjs` is an explicit pinned offline field projection; it never runs upstream sync. `archive.ts` defines every generated field. No gameplay cost, power, RAM, eddies, ability, rules, flavor, descriptions, image bytes, image URLs or official layout is incorporated.

## U.S. basis and limits

The [Copyright Office Compendium §313.3(C)](https://www.copyright.gov/comp3/chap300/ch300-copyrightable-authorship.pdf) distinguishes facts from their expression. [Circular 33](https://www.copyright.gov/circs/circ33.pdf) excludes names/short titles and systems while preserving expressive descriptions. This supports reuse of these identifiers, labels and factual product attributes without demanding a separate license for each fact. A fictional game's expressive setting does not make all functional card identifiers protected prose. This is a reasoned assessment of these actual short values, not a rule that any string in a database is free to copy.

[Copyright Office Circular 14](https://www.copyright.gov/circs/circ14.pdf) distinguishes original selection/coordination/arrangement from mechanical compilations. This extraction includes the entire available 151-card set, selects utilitarian identity fields, and mechanically sorts by UUID in a Community schema. It does not reproduce the Archive presentation or editorial features. Those facts support low creative-compilation exposure, but underlying membership/groupings and source identifiers remain derived; no court has assessed this particular database. Effort alone does not make each fact copyrightable. Non-U.S. database rights, parties' locations, substantial extraction and contractual liability remain unassessed; this is a small U.S.-focused release review, not global clearance.

## Fan guidance and branding

No approval or membership is claimed. This free utility has no payment, advertising, game simulation, copied assets or AI artwork. The word licensing in its fan-creation rule creates uncertainty for an open-source project: MIT should cover only independently owned utility code, never a grant over game IP or the catalog. That scope distinction is a reasoned position, not a WeirdCo exemption. Source presence before Retail release does not prove every promo was officially announced; coverage remains provisional, not a news/leak feed.

This static browser collection website, with optional PWA installation and no gameplay, fits the website rationale; the broad mobile-app wording could nevertheless be applied to its installable phone use.
