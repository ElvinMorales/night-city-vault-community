# Artwork confidence

Pure resolution uses caller-supplied content-addressed local blob availability, never paths or network requests. Confidence exact/generic/missing is independent of identity certainty and redistribution rights. Entries require matching card, permitted local-display rights with evidence, image and optional thumbnail availability. Exact additionally needs same-card printing and evidence; generic cannot claim a printing.

Exact wins only for its printing. Canonical/unresolved views use generic or missing. Multiple candidates produce missing+review. Generic fallback on promo/Iconic targets needs review. Coverage counts printings once, or canonical rows for cards without printings.

Owner attestation is retained solely as the baseline local-display policy, never as a redistribution grant. Restricted/unverified entries are rejected. The resolver uses explicit card IDs only; legacy canonical-name lookup was deliberately omitted to prevent ambiguous matching. Blob validation and hashing are deferred; symbolic fictional blob IDs in tests are not assets. Resolver calls cannot write inventory.

Future commands must require explicit confirmation for exact replacement/removal, retain provenance and permit generic verification without duplicating bytes. No artwork mutation implementation is included in Phase 0.

## Phase 3A local-display extension

The Phase 0 deferred-implementation notes above describe the baseline. Personal imports now use source personal-local, rightsStatus unverified, and the precise informational acknowledgment. This is an explicit local-display path, not owner attestation. Other unverified sources remain rejected. Exact associations require selection, written evidence and explicit user confirmation and never upgrade physical printing confidence, including Archive references with unknown treatment. Generic remains a gameplay association. Ambiguity and special-printing review policies remain in force. Processed byte hashes, provenance and thumbnails are transactionally persisted and recoverable through complete community-media@3 backups.
