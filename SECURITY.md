# Security and private reports

Night City Vault Community Edition is a **public beta**, deployed on GitHub Pages. It has no application login, collection server, analytics or cloud synchronization. Inventory, history and personal card photos are stored in browser IndexedDB. This is neither encrypted storage nor a guaranteed backup.

**Keep full `.ncv` backups private.** They may contain personal images, custom notes and complete collection history. Do not post backups, personal photos, credentials or private inventory details in GitHub issues or Discord channels.

For ordinary bugs and usability problems, use the [public issue forms](https://github.com/ElvinMorales/night-city-vault-community/issues/new/choose) with fictional or redacted examples.

For a vulnerability that could expose data or cause serious loss, **do not disclose technical exploit details in a public issue**. Use GitHub's private vulnerability reporting if it is enabled for this repository. If that option is unavailable, request a private contact route from the maintainer through an existing shared community channel **without posting the sensitive details**. No dedicated security inbox or guaranteed response time is configured.

Supported fixes target the current public beta and later approved releases. Browser storage, offline availability and physical-device behavior may vary; make an external backup before troubleshooting or clearing data.
