# Security

The app has no server, login, telemetry or cloud synchronization. Inventory and photos live in browser IndexedDB; this is not encrypted storage or a guaranteed backup. Download full backups and keep them private: they can contain personal images and collection history.

Do not include collection exports, photos or credentials in public issues. For a sensitive vulnerability, use GitHub's private vulnerability reporting on the target repository once the owner has enabled it. Until then contact the owner through an established private channel; no dedicated security mailbox is configured. Supported security fixes will target the latest approved release; none is published yet.
