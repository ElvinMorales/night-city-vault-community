# Changelog

## 0.1.0 — Public community beta (2026-11-16)

- Launched the free, unofficial local-first collection tracker on GitHub Pages.
- Bundled 151 gameplay card identities and 860 source printing references, with physical treatment certainty and completeness limitations disclosed.
- Included Binder, Pack Desk, Playsets, Extras and explicit trade marks.
- Included special-version selection, personal card photos, recent-change Undo and Recent Activity.
- Included full media-inclusive `.ncv` backups and guarded replacement restore, offline PWA support and mobile layouts.
- GitHub Actions verification passed on the deployed main commit, including Chromium/WebKit automation and the public-release audit.
- **Known limitations:** no cloud sync or automatic backup; local browser storage can be cleared or evicted; physical iPhone/Home Screen, camera/HEIC and VoiceOver acceptance are incomplete.

For future releases, include player-visible changes, backup/storage compatibility, verification results and unresolved limitations. Do not put private diagnostics or real collection records in release notes.
